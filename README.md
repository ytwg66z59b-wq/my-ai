# my-ai

サービス紹介動画制作向けランディングページ（プレースホルダーブランド）。

## 技術スタック

- Vite
- Vanilla JS + CSS Variables

## 開発

```bash
npm install
npm run dev
```

## コンテンツ差し替え

| 変更したいもの | 編集場所 |
| --- | --- |
| 文章・見出し・CTA | `src/content.js` |
| カラー・余白・タイポ | `src/styles/tokens.css` |
| レイアウト・セクション見た目 | `src/styles/main.css` |
