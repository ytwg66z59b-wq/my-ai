# Halo — Voice AI for meetings

[Krisp.ai](https://krisp.ai/) にインスパイアした、ブラウザ完結の Voice AI ミーティング Web アプリです。

- ノイズキャンセル（ブラウザ制約 + Web Audio フィルタ）
- リアルタイム文字起こし（Web Speech API）
- AI ミーティングノート（要点・アクション抽出）

## 開発

```bash
npm install
npm run dev
```

## ビルド / テスト

```bash
npm run build
npm test
npm run lint
```
