# いま振る — 簡易シフトボード

メンバーの稼働状況をひと目で把握し、「今、誰に仕事を振ればいいか」を直感的に判断するツールです。

## 機能

- 🟢 即レスOK / 🟡 30分以内ならOK / 🔴 返信不可 を一覧表示
- 対応できる人を上に並べる「今、誰に振る？」リスト
- 15分刻みの稼働バー（指で伸縮、タップで状態変更）
- 「あと何分で対応可能」の表示
- 画面上部に現在時刻と人数サマリーを固定表示

## 開発

```bash
npm install
npm run dev
```

## テスト / ビルド

```bash
npm test
npm run build
```
