# DRAGON DAYS

毎日の「頑張った！」が卵を孵し、幻獣を育てるスマホ対応 Web アプリです。

## 開発

```bash
npm install
npm run dev
```

## テスト / ビルド

```bash
npm test
npm run build
npm run preview
```

## 主な機能

- 日次カウント（日本時間 0 時切替）・累計・カレンダー
- 複数卵・分岐進化・救済上限付き進化判定
- 図鑑・起動時名言・IndexedDB 保存
- JSON バックアップのエクスポート / インポート
- PWA（マニフェスト + Service Worker）

キャラクター画像の差し替え一覧は `docs/ASSETS.md` を参照してください。
