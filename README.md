# いま振る — 対応可能時間ボード

業務委託・フリーランス向けに、メンバーの対応可能時間を共有し「今誰に仕事を振るか」を判断するツールです。

## 公開URL

https://ytwg66z59b-wq.github.io/my-ai/shift/

## はじめ方

1. 自分の名前でアカウントを作成
2. 「自分のシフト」で空き時間を入力（他人のシフトは編集不可）
3. 「管理画面」で全員の対応状況を確認

## 開発

```bash
npm install
npm run dev
```

## テスト / ビルド

```bash
npm test
npm run build
```
