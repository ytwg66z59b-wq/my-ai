# いま振る — 対応可能時間ボード

業務委託・フリーランス向けに、メンバーの対応可能時間を共有し「今誰に仕事を振るか」を判断するツールです。

## 公開URL

https://ytwg66z59b-wq.github.io/my-ai/shift/

## 画面

- **管理画面**: 今対応できる人 / 日・週・月の稼働確認 / 現在時刻ライン
- **シフト入力**: 終日OK・休日・時間指定、バーの移動・伸縮・分割、長押しメニュー、コピー、曜日テンプレ、自動保存

## 開発

```bash
npm install
npm run dev
```

## テスト / ビルド

```bash

npm run build
```
